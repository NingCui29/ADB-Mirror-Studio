# 当前设备 CPU/GPU/内存占用与温度监测

设备工作区的“概览”显示当前选中设备的整机 CPU、GPU、内存当前占用和最近 30 秒平均占用。采样约每 2 秒执行一次；平均值仅使用最近 30 秒内实际取得的有效样本，不把缺失值算作 0。

同一采样还读取 `/sys/class/thermal/thermal_zone*/type` 和 `temp`，显示 CPU 与 GPU 当前温度。内核热区接口的 `temp` 单位为千分之一摄氏度；界面换算为 °C。CPU 可能有多个核心或集群热区，界面取明确标记为 CPU/core/cluster 的热区中最高温度，并标注“最高热区”；GPU 取明确标记为 GPU/Mali/Adreno 的热区。SoC、机身、电池等其他热区不会冒充 CPU 或 GPU。没有可读且有效的对应热区时显示“不可用”。温度不计算 30 秒平均值。

- CPU 当前值由两次 `/proc/stat` 整机计数器之差计算。首次采样只能建立基线，显示“计算中”；显示的是整个设备所有 CPU 核心合计的忙碌比例，不是某个应用的 CPU 占用。`idle` 和 `iowait` 计入非忙碌时间。
- GPU 当前值读取设备上可访问的 GPU 驱动 `load` 或 Mali `utilization` 节点。不同厂商的节点和权限并不统一；没有可读节点、格式不受支持时显示“不可用”，不会用 GPU 频率、帧率或 CPU 值代替。
- 内存当前值读取 `/proc/meminfo`，按 `(MemTotal - MemAvailable) / MemTotal` 计算。`MemAvailable` 是在无需交换的情况下可供新应用使用的估算内存，因此文件缓存等可回收内存不会被简单视为已占用。界面同时显示已用量和总量，容量按 GiB 换算。
- 切换目标设备或目标离线时立即清空旧设备的当前值与平均值；在途采样会取消，迟到结果不会覆盖新设备。
- 采样命令只读取设备文件，不修改设备配置。采样失败会在性能区域提示并在下一轮重试，不影响镜像和文件任务。

这项功能目前已在 `10.67.116.12:5555`（Android 12、Mali GPU）验证 CPU、GPU 和内存动态占用读数。该设备提供 `/sys/class/devfreq/fb000000.gpu/load`，CPU 温度来自 `bigcore0-thermal` 等核心热区，GPU 温度来自 `gpu-thermal`。不同芯片和 Android 版本的 GPU 占用及温度节点仍需分别验收。
