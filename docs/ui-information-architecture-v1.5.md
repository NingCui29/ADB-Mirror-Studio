# ADB Mirror Studio V1.5 UI 信息架构

## 1. 设计基准

本方案只依据产品当前提供的能力重新建模，不沿用既有页面、菜单或标签结构。

产品中的信息只有三种作用域：

1. **设备作用域**：针对一台 Android 设备执行的操作。
2. **跨设备任务作用域**：可能持续运行、需要查看进度或历史结果的任务。
3. **应用作用域**：影响桌面应用本身的配置、健康状态和版本维护。

由此形成三个界面层级：

- 设备工作区
- 任务中心
- 设置中心

## 2. 主界面结构

```text
┌─────────────────────────────────────────────────────────────────────┐
│ ADB Mirror Studio                   任务 2          帮助    设置    │
├──────────────────┬──────────────────────────────────────────────────┤
│ 设备             │ Pixel 8 · Android 15 · USB · 在线              │
│                  ├──────────────────────────────────────────────────┤
│ ● Pixel 8        │ 概览   屏幕   文件   应用   终端                │
│ ● Tablet         ├──────────────────────────────────────────────────┤
│ ○ 192.168.1.8    │                                                  │
│                  │ 当前设备功能内容                                 │
│ ＋ 添加设备      │                                                  │
│ ↻ 刷新           │                                                  │
└──────────────────┴──────────────────────────────────────────────────┘
```

左侧始终表示设备，不再把设备选择器重复放进各功能页面。右侧始终表示当前设备。顶部的任务中心聚合跨设备运行状态，设置只管理桌面应用本身。

### 无设备状态

没有在线设备时，右侧显示单一引导页：

- USB 连接说明
- 无线地址连接
- 无线配对
- 重新扫描
- 打开诊断

设备出现后立即进入该设备的“概览”。只有一台在线设备时可以自动选中；有多台设备时保留用户上次明确选择的设备。

## 3. 设备工作区

### 3.1 概览

概览回答“这台设备现在是否可用”。

内容：

- 型号、序列号、Android 版本、分辨率、电量、存储
- USB 或 TCP/IP 连接状态
- 快捷操作：开始镜像、发送文件、截图
- 连接管理：启用 TCP/IP、断开连接、重启设备

“断开连接”和“重启设备”进入次要操作区，并保留确认步骤。概览不放应用列表、Shell 或日志输出。

### 3.2 屏幕

屏幕回答“如何查看、控制和记录这台设备”。

内容：

- 流畅、均衡、高清、演示四种预设
- 音频、帧率、分辨率、码率和窗口行为
- 开始/停止镜像
- 开始/停止录屏与保存路径
- 返回、主页、最近任务、电源和音量控制
- 截图
- 当前会话状态、编码器、音频状态和错误恢复

页面的唯一主操作根据状态在“开始镜像”和“停止镜像”之间切换。高级参数默认折叠；选择预设后只展示与预设不同的自定义项。

### 3.3 文件

文件回答“如何在电脑和设备之间交换内容”。

内容：

- 发送到设备：选择或拖入多个本地文件，设置远端目录
- 从设备获取：填写远端路径，选择本地目录
- 当前设备的传输队列和结果

APK 不归入文件页。APK 的用户目标是安装应用，因此归入“应用”。

### 3.4 应用

应用回答“如何安装和管理设备上的应用”。

内容：

- 安装 APK
- 用户应用列表
- 可选显示系统应用
- 搜索包名
- 启动、强制停止、卸载

应用列表采用行级操作。启动是主要操作；强制停止和卸载收进每行的更多菜单，卸载必须二次确认。直接输入包名卸载放入高级区，不占用首屏。

### 3.5 终端

终端回答“如何获取设备级调试信息并执行命令”。

内容：

- ADB Shell 命令输入、运行、取消、清空和输出
- 导出 Logcat
- 常用只读命令模板

终端首次进入时显示风险说明。普通设备操作不会出现在终端页，防止专业工具干扰日常使用。

## 4. 任务中心

任务中心只收纳跨页面、跨设备或持续运行的对象，不再承担功能配置。

### 正在运行

- 所有镜像与录屏会话
- 文件上传和下载
- 更新包下载
- Shell 长任务

每项展示目标设备、状态、进度、开始时间以及可用的停止或重试操作。

### 已完成

- 录像文件及打开目录
- 截图和日志导出结果
- 文件传输结果
- 最近失败任务及错误详情

### 多窗口

有两个及以上镜像会话时显示网格、横向和纵向排列操作。单一会话不展示窗口排列功能。

任务中心入口在顶部显示运行数量和失败标记。完成且无需处理的任务不会持续占用全局提示区域。

## 5. 设置中心

设置中心采用纵向分区，不使用文档式标签页。

### 常规

- 主题
- 自动刷新设备
- 默认镜像预设
- 默认保存目录

### 连接

- 已记住的无线地址
- 清除连接历史
- 配对和连接行为说明

### 系统健康

- ADB、scrcpy 和运行环境检查
- ADB 冲突检测
- 一键复制诊断结果

### 更新

- 当前版本
- 检查更新
- 下载进度、校验状态和发布说明

### 数据与关于

- 打开应用数据目录
- 许可证
- 项目与发布页面

## 6. 功能归属清单

| 能力 | 新位置 |
|---|---|
| 扫描、发现设备 | 左侧设备栏 |
| 地址连接、无线配对 | “添加设备”面板 |
| 连接历史 | 添加设备建议项；管理入口位于设置/连接 |
| 设备详情 | 设备/概览 |
| TCP/IP、断开、重启 | 设备/概览/连接管理 |
| 镜像参数、开始与停止 | 设备/屏幕 |
| 录屏 | 设备/屏幕 |
| 返回、主页、最近任务、电源、音量 | 设备/屏幕 |
| 截图 | 设备/屏幕；结果进入任务中心 |
| 文件上传、下载 | 设备/文件 |
| APK 安装 | 设备/应用 |
| 应用启动、强停、卸载 | 设备/应用 |
| ADB Shell | 设备/终端 |
| Logcat | 设备/终端；结果进入任务中心 |
| 多镜像窗口排列 | 任务中心/多窗口 |
| 录像与导出历史 | 任务中心/已完成 |
| 环境诊断 | 设置/系统健康 |
| 更新 | 设置/更新；下载进度进入任务中心 |
| 主题、自动刷新、数据目录、关于 | 设置 |

## 7. 反馈与状态规则

- 页面内操作在原位置显示进度和结果。
- 任务离开当前页面后，由任务中心继续显示状态。
- 普通成功使用短暂通知，不创建永久信息条。
- 错误提示必须包含对象、失败步骤、错误原因和恢复操作。
- 设备断开时保留原设备上下文并显示离线状态，不自动把操作目标换成另一台设备。
- 同一设备上的冲突操作互斥，不相关设备和不相关任务可以并行。

## 8. 响应式规则

- 宽度不小于 1500 px：设备栏与内容区同时显示，概览、屏幕、文件和应用卡片使用双列，内容最大宽度为 1400 px。
- 980–1499 px：设备栏与内容区同时显示，功能卡片恢复单列。
- 小于 980 px：设备栏移动到内容上方，设备工作区占据完整可用宽度并保留纵向滚动。
- 任务中心和设置中心保持居中的完整页面布局。
- 主操作保持可见；高级参数、危险操作和低频说明允许折叠。

## 9. 实施边界

该结构要求共享一个明确的当前设备上下文，并将设备状态、镜像会话、传输任务和应用设置拆成独立状态域。界面不应再由单个页面和单个全局忙碌状态统一控制。

第一阶段先建立新壳层、设备栏和五个设备工作区，不改变底层 ADB 与 scrcpy 行为。第二阶段接入统一任务中心。第三阶段再做视觉主题、动效、键盘导航和不同 DPI 下的视觉验收。
