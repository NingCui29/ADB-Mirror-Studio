# ADB Mirror Studio V1.8.0

`V1.8.0` 在当前设备性能区域加入整机 DDR 带宽监测，并保留已有 CPU、GPU、内存容量和温度监测。现有设置、镜像、录屏、文件传输和设备管理流程保持兼容，全部功能继续免费。

## 新增与改进

- 读取设备 devfreq 的 DMC/DDR `load` 节点，显示 DDR 当前带宽占用。
- 显示最近 30 秒有效 DDR 样本平均值，以及节点返回的当前 DDR 工作频率。
- DDR 带宽活动与内存容量占用分开显示，避免混淆两个含义不同的指标。
- 每轮最多读取三次并仅采用 0–100% 的有效值，过滤部分 Rockchip 内核间歇返回的越界瞬时值。
- CPU、GPU、内存和 DDR 调整为 2×2 卡片布局，窄窗口中保持可读。
- 设备没有公开可读 DMC/DDR 节点时显示“不可用”，不会用内存容量、频率或其他总线指标代替。

## 验证与边界

- Release x64 构建和 235 项单元测试通过。
- Android 12 真机 `10.67.116.12:5555` 上读取 `/sys/class/devfreq/dmc/load`，连续界面采样显示动态 DDR 占用、30 秒平均值和 `2.112 GHz` 频率。
- 真机驱动会间歇返回超过 100 的异常值；三次有限重读与有效范围过滤已经回归验证。
- DDR 数据依赖设备内核公开的 devfreq DMC/DDR 节点，不支持的设备会明确显示“不可用”。
- 最终便携 ZIP 独立解压启动通过，应用内版本、当前设备和 DDR 数据显示正常。
