# ADB Mirror Studio V2.0.0-2026.11.25

## 主要改动

- 每个镜像窗口顶部新增独立的快捷工具条，提供返回、主屏、最近应用、电源、音量和截图。工具条与标题栏齐高，随窗口移动和缩放，只操作该窗口对应的设备。
- 支持用 `Ctrl+K` 打开快捷命令面板，拖放 APK 或普通文件到镜像卡片，并从镜像页面导出 Logcat 或打开终端。
- 改进设备 Shell 命令执行、文件传输和设置写入，使错误和取消能够正确反馈。
- 界面、安装器和文件名使用同一完整版本号。检查更新时先比较三段基础版本号，再比较打包日期。新版安装包启动前会校验文件名、包内版本、大小和 SHA256。
- 覆盖安装时先等待应用正常退出。超时后可确认强制关闭当前安装目录中的应用和随包工具，再继续安装。

## 安装与升级

- 安装版和便携版均支持 Windows x64。下载文件及 SHA256 见 [GitHub Release](https://github.com/NingCui29/ADB-Mirror-Studio/releases/tag/V2.0.0-2026.11.25)。
- 早期 `V2.0.0` 客户端需要从发行页下载新版安装包并覆盖安装。此版本起，客户端可识别同一基础版本下日期较新的发行版。
- 安装器尚未配置 Authenticode 签名，请从本仓库的发行页下载并核对 SHA256。
