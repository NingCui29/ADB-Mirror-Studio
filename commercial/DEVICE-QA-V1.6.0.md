# ADB Mirror Studio V1.6.0 真机验收

测试设备：`10.67.116.12:5555`，Android 12，Mali GPU，Windows x64 桌面客户端。

| 项目 | 结果 |
|---|---|
| 当前设备整机 CPU 占用与 30 秒平均值 | 连续采样值随设备负载变化 |
| 当前设备 GPU 占用与 30 秒平均值 | `/sys/class/devfreq/fb000000.gpu/load` 可读，界面值持续变化 |
| CPU 温度 | `bigcore0-thermal`、`bigcore1-thermal`、`littlecore-thermal` 可读，显示其中最高读数；观察到 63.8→64.7 °C |
| GPU 温度 | `gpu-thermal` 可读；观察到 61.0→61.9 °C |
| 设备切换 | 单元测试确认旧设备在途结果不会覆盖新设备，切换后清空旧读数 |
| 600×650 窄窗口 | “概览”可滚动查看两项占用、平均值和温度，无横向裁切 |
| V1.6.0 便携包 | 独立解压启动，版本标识、当前设备占用和温度读数正常 |

其他厂商 GPU 占用节点和 CPU/GPU 热区命名尚未真机覆盖；缺失或格式无效时应显示“不可用”。本次验收范围是新增的只读性能监测，未重新执行 V1.5.0 的完整镜像、录屏、传输和安装矩阵。
