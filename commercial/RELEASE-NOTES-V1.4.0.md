# ADB Mirror Studio V1.4.0

`V1.4.0` 是兼容 `V1.3.2` 设置与使用方式的稳定性升级，集中修复镜像、录屏、设备操作、文件传输和更新发布流程，全部功能继续免费。

## 修复与改进

- 修复电脑没有默认音频输出设备时镜像或录屏报 `Demuxer error`：自动关闭电脑侧音频播放，录屏仍可保留设备音轨；错误提示优先显示具体原因。
- 修复镜像启动、停止、重启和退出之间的并发问题；退出时等待会话回收，避免进程残留和录屏切换状态错乱。
- 录屏拒绝覆盖已有非空文件；强制终止或异常退出会明确提示文件可能不完整，避免误报录制完成。
- 修复编码器能力缓存影响质量预设的问题，按设备能力分别选择 H.264/H.265；保留四档预设和录屏切换失败恢复。
- 设备刷新保留有效选择和应用列表；当前目标断开后保持未选择，等待手动确认；确认对话框固定设备和操作参数，避免操作落到其他设备。
- 修复取消后仍显示完成、旧请求覆盖新状态和关闭页面后继续刷新等问题；APK 安装路径与普通上传队列独立。
- 修复 Windows ADB 对中文文件名和递归目录名的处理问题，支持中文、空格、特殊字符、嵌套目录和空目录下载；单文件先临时下载，成功后替换同名文件。
- 修复 ADB Shell 参数丢失、连接和配对失败误报成功、系统应用分类及截图失败覆盖原文件等问题。
- 加强设置原子写入、命令超时与输出回收、更新包大小和 SHA256 校验；启动安装器前再次验证文件，更新退出共用正常清理流程。
- 安装器等待应用正常退出，卸载按发行文件清单清理并保留用户额外文件；发布校验覆盖运行时、WinUI 资源及随包工具，清理临时目录失败不再掩盖构建结果。
- 统一当前 GitHub 仓库地址、版本元数据和下载链接；隐私审计覆盖未忽略的新增文件及 Unicode 路径。

## 验证

- Release 自包含发布构建和 NSIS 安装器编译通过。
- 208 项自动化测试、27 项发行脚本检查及隐私审计通过；便携 ZIP 的 530 个条目完整性校验通过。
- V1.4.0 便携版解压启动、重复启动单实例和正常退出通过。
- 在独立目录中完成正式 V1.3.2 覆盖升级至 V1.4.0、新版空目录安装、启动与正常退出、静默卸载和额外用户文件保留验收。
- Android 12 真机四种镜像预设、MP4/MKV 录屏切换及完整音视频解码通过。

目录下载按文件逐项提交，超过 10,000 个条目或目录列表过大时需要分批下载。跨 Android/Windows 版本、多设备、不同 DPI 和长时间压力测试尚未全覆盖。
