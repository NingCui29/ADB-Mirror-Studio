# ADB Mirror Studio V1.6.0

`V1.6.0` 在当前设备“概览”中加入整机 CPU、GPU 占用和温度监测，保持原有镜像、录屏、文件传输和设备管理方式兼容。全部功能继续免费。

## 新增与改进

- 约每 2 秒刷新当前选中设备的整机 CPU/GPU 占用，并显示最近 30 秒有效采样的平均占用。
- 同时显示 CPU 最高热区和 GPU 专属热区的当前温度；传感器缺失或无法识别时显示“不可用”，不以 SoC、电池或其他指标代替。
- 切换设备或目标离线时立即清空原设备读数，并丢弃迟到的采样结果。
- 性能采样失败只影响性能区域，下一轮自动重试，不中断镜像和文件任务。

## 验证与边界

- Release x64 自包含构建、224 项单元测试和 26 项发行脚本检查通过。
- Android 12 真机 `10.67.116.12:5555` 上观察到 CPU/GPU 占用和温度动态变化；使用 Mali GPU 的 `load` 节点与 CPU/GPU 热区节点。
- 100% DPI 下检查了 600×650 窄窗口，滚动后两项温度均可见。
- 便携 ZIP 独立解压启动后显示 V1.6.0，真机 CPU/GPU 占用和温度继续更新。
- GPU 占用和温度节点由设备厂商提供，尚未覆盖其他芯片及 Android 版本；不支持的设备显示“不可用”。
