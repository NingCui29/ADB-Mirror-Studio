# ADB Mirror Studio V1.8.0 真机验收

测试设备：`10.67.116.12:5555`，Android 12，Rockchip 5.10 内核，Mali GPU，Windows x64 桌面客户端。

| 项目 | 结果 |
|---|---|
| DDR 数据源 | `/sys/class/devfreq/dmc/load` 可读，输出占用值与当前频率 |
| 当前占用 | 连续 8 次界面检查均显示有效动态读数，观测范围 12.0%–21.0% |
| 30 秒平均值 | 随有效样本窗口从 18.2% 更新至 15.0% |
| DDR 频率 | 界面持续显示 `2.112 GHz` |
| 异常样本 | 设备节点可间歇返回 950、1217、1434 等越界值；程序拒绝超过 100 的值并从最多三次读取中选择首个有效样本 |
| 有效样本重读 | 10 轮三次读取验证均至少得到一个 0–100% 有效样本 |
| 不支持设备 | 自动化测试确认节点缺失或三次数据均无效时显示“不可用” |
| 设备切换 | 自动化测试确认切换后清空旧读数，旧设备在途结果不会覆盖新设备 |
| 性能布局 | CPU、GPU、内存、DDR 使用 2×2 卡片布局，Release 构建通过 |
| 最终便携包 | 从最终 ZIP 独立解压后启动成功；界面版本为 `V1.8.0`，当前设备正确，DDR 显示 13.0%、30 秒平均 12.7%、频率 `2.112 GHz` |

本次验收覆盖新增 DDR 带宽监测、异常样本过滤、相关布局和便携构建启动；未重复执行 V1.7.0 的完整镜像、录屏、传输和安装矩阵。
