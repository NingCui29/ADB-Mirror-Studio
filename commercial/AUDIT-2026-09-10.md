## 关键问题与修复

| 范围 | 已确认问题 | 修复后的行为 |
|---|---|---|
| 音频与 Demuxer | 本机没有默认音频输出设备，scrcpy 先报音频打开失败，随后报通用 Demuxer 错误 | 启动时检测 Windows 默认输出；不可用时加入 `--no-audio-playback`，保留录屏音轨；优先展示具体原因 |
| 会话启动 | 设备锁内等待退出观察任务，观察任务的清理又需要同一把锁，快速退出被错误归类为启动成功或超时 | 分离进程退出与加锁清理，及时报告启动失败 |
| 停止与重启 | 并发停止、重启、取消和退出可能交叉，旧会话可能释放新会话的录屏路径 | 同设备操作串行；按会话 ID 释放资源；停止返回前完成回收；退出等待所有在途启动和活动会话 |
| 录屏文件 | 已有文件可能被覆盖，强制终止或非零退出仍可能显示完成 | 拒绝已有非空文件；支持保存对话框的零字节占位文件；强杀、异常退出标为失败并保留具体原因 |
| 进程输出 | 子进程继承 stdout/stderr 后，父进程退出仍可能一直等待输出结束 | 通用命令超时覆盖输出读取；镜像退出后最多再排空输出 2 秒；取消时保留已采集的诊断尾部 |
| 预设与能力缓存 | 只比较部分配置；编码器缓存混入某次预设选择，影响后续预设 | 比较完整请求配置；缓存设备能力，每次按预设选择编码器，失败查询不缓存 |
| 设备刷新 | 每 5 秒重建列表清空选择或应用列表；断开后可能自动切换操作目标 | 复用未变化卡片；后台刷新不覆盖任务状态；目标丢失后保持未选择，等待手动选择 |
| 操作确认 | 确认对话框或文件选择器打开期间切换设备，操作可能落到新目标 | 发起时固定设备、包名或命令，确认后使用同一份参数 |
| 异步界面状态 | 旧请求结果覆盖新设备状态；取消后出现完成提示；关闭后继续刷新界面 | 页面生命周期取消；设备/请求版本检查；提交结果前检查取消；丢弃过期会话事件 |
| 文件队列 | APK 路径与上传路径共用，手动改路径后队列仍保留旧文件 | 两种路径独立；手动修改上传路径同步队列；重试重置状态；正确统计成功和取消 |
| ADB 命令 | 额外 `sh -c` 层导致参数被 ADB 拼接后丢失；连接失败可能仍返回退出码 0 | Shell 作为完整命令传给 ADB；连接和配对验证成功回执；错误优先使用 stderr |
| ADB 路径 | 本机随包 ADB 对中文文件/递归目录名的处理可产生截断或 `Illegal byte sequence` | Android 侧以 NUL 分隔枚举目录；.NET 创建层级和空目录；每个文件下载到明确的临时文件全路径，成功后替换 |
| 下载边界 | 原有递归下载依赖 ADB 的路径处理和失败行为 | 写入前校验完整列表、根路径、Windows 名称、大小写碰撞和目录结构；条目/输出大小有限制；单文件失败保留其原目标 |
| 截图 | 失败的下载可能破坏原目标图片 | 独立本地临时文件，成功后替换，远端临时截图尽力清理 |
| 设置保存 | 多个设置存储实例共用固定临时文件，可能相互干扰 | 按规范化路径共享进程内锁，独立临时文件和原子替换 |
| 更新下载 | 并发临时路径冲突、长度检查不足、校验后到启动前文件可能被替换 | 独立临时下载，检查大小、SHA256 和最终地址；启动前再次校验并持有只读文件句柄 |
| 更新退出 | 程序化关闭窗口不保证触发 AppWindow.Closing，可能未清理镜像 | 窗口关闭与更新安装共用异步 ShutdownAsync，先停止会话和清理工具，再关闭窗口 |
| 诊断 | 文件存在被误写为完整性验证，空组件仍可能通过 | 空文件报错；存在性与完整性明确区分；取消向上传递 |
| 发布与卸载 | 包缺失必要依赖仍可继续，递归卸载可能删除用户额外文件，全局进程名终止可能影响别的实例 | 校验版本和必需负载，临时产物成功后替换；按发行清单卸载；针对安装目录检查应用占用 |
| 发布清理 | 完整便携包构建成功后，清理临时目录失败使整个脚本报失败，也可能掩盖更早的错误 | 路径验证后单次尽力清理，清理异常仅警告；保留成功结果或原始构建异常 |
| 隐私检查 | 只扫描已跟踪文件，遗漏新增文件、Unicode 路径和部分本机用户路径 | 以 UTF-8/NUL 获取 Git 文件列表，同时检查未忽略新增文件；补齐敏感文件和路径规则 |

## 可重复执行

在仓库根目录用 .NET 10 SDK：

```powershell
.\.tools\dotnet\dotnet.exe test commercial/tests/AdbMirrorStudio.UnitTests/AdbMirrorStudio.UnitTests.csproj -c Release
.\.tools\dotnet\dotnet.exe build commercial/src/AdbMirrorStudio.App/AdbMirrorStudio.App.csproj -c Release -r win-x64 /p:Unpackaged=true
.\commercial\scripts\test-privacy.ps1
.\commercial\scripts\test-release-scripts.ps1 -AppBuildDirectory <WinUI构建输出目录> -NsisCompilerPath <makensis.exe>
.\commercial\scripts\build-installer.ps1 -NsisCompilerPath <makensis.exe>
```

`build-installer.ps1` 默认先运行测试和便携发布构建；`-SkipPortableBuild` 仅在核对已有便携包版本和负载后复用。生成本地安装器不等于执行了真实安装、升级和卸载。

## 尚未覆盖的验收

- 本轮设备验证为一台 Android 12 TCP/IP 设备；未扩展到 USB 热拔插、多个真实设备、Android 11+ 新配对、其他 Android/Windows 版本或长时间压力测试。
- ViewModel 测试链接真实生产逻辑，测试宿主替代 WinUI 展示类型；不能证明实际按钮流程、对话框、DPI、多显示器布局和无障碍体验。
- APK 安装/卸载、设备重启、更新安装执行通过命令与状态回归检查，未在本轮真实执行这些会影响环境的操作。
- 设置写入锁为进程内锁；下载校验是在 HTTP 重定向完成后检查最终地址；通用命令对输出等待有上限，但不承诺回收已脱离父进程的所有后代进程。
- 目录下载按文件逐个提交，后续文件失败不会回滚已成功下载的文件；不是整目录事务替换。
- 本轮没有签名、推送或发布新版本；正式发布需依照 `VERSIONING.md` 递增版本并完成发行验收。
