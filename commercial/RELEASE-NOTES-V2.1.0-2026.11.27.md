# ADB Mirror Studio V2.1.0-2026.11.27

## 新功能

- 在“应用管理 → 界面测试”读取在线设备或模拟器的控件树，用文字、资源 ID 或无障碍描述选择控件。可以编排应用启动、点击、输入、滑动、返回和可见性断言，并按步骤保存截图和 Logcat。每次运行生成独立报告。
- 向“屏幕镜像”卡片拖入多个 APK 和普通文件时，每批都会记录自己的目标设备与文件清单。程序先安装 APK，再推送普通文件。切换设备并再次拖放会创建另一批任务。
- 在“任务中心 → 镜像页拖放记录”查看每个文件的操作和结果。单项失败后会继续处理余项，也可以取消当前批次。截图、安装和传输提示按实际执行结果显示。

## 下载与升级

- Windows x64 安装版支持覆盖升级。V2.0.0 和 V2.0.1 用户可在设置中检查更新。便携版用户可退出旧版、完整解压新版后启动。
- 安装器和便携包附有 SHA256 校验值。无日期的安装器文件名供旧更新器使用，其内容与带日期的安装器相同。
- 安装器未配置 Authenticode 签名，Windows 可能提示“未知发布者”。请从本仓库下载并核对校验值。[GitHub 发行页](https://github.com/NingCui29/ADB-Mirror-Studio/releases/tag/V2.1.0-2026.11.27)
