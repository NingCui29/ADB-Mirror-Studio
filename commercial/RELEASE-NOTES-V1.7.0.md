# ADB Mirror Studio V1.7.0

`V1.7.0` 在当前设备性能区域加入整机内存占用监测，并保留 V1.6.0 的 CPU、GPU 占用与温度功能。现有设置、镜像、录屏、文件传输和设备管理流程保持兼容，全部功能继续免费。

## 新增与改进

- 约每 2 秒读取当前选中设备的 `MemTotal` 与 `MemAvailable`，显示整机内存当前占用。
- 显示最近 30 秒有效样本的平均内存占用，以及已用内存与总内存的 GiB 数值。
- 使用 `MemAvailable` 估算可供新应用使用的内存，避免把可回收文件缓存简单计为已占用。
- 切换设备、设备离线或采样失败时清空原设备的内存数据，不让迟到结果覆盖当前设备。
- CPU、GPU、内存三列在 600×650 窄窗口中保持可读，并缩短平均值标签以避免横向裁切。

## 验证与边界

- Release x64 构建和 229 项单元测试通过。
- Android 12 真机 `10.67.116.12:5555` 上显示 79.2%，已用 6.1 / 7.7 GiB，与同一时刻 `/proc/meminfo` 计算结果一致。
- 100% DPI 下检查了最大化和 600×650 窄窗口布局。
- 设备缺少有效 `MemAvailable` 时显示“不可用”，不会使用不准确的替代计算。
