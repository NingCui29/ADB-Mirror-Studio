# ADB Mirror Studio V1.5.0

`V1.5.0` 重新组织桌面端信息架构，使设备选择、单设备操作、跨设备任务和应用设置各自具有明确作用域。ADB、scrcpy、文件传输、应用管理和更新服务的底层行为保持兼容。

## 界面与交互

- 新增固定设备栏，所有设备操作共享同一个当前目标。
- 将单设备能力归为概览、屏幕、文件、应用和终端五个工作区。
- 镜像启动、画质预设、录屏、按键控制和截图统一归入屏幕工作区。
- APK 安装和包管理统一归入应用工作区。
- ADB Shell 与 Logcat 统一归入终端工作区。
- 新增任务中心，集中展示镜像会话、文件任务、录屏文件和多窗口排列。
- 设置中心改为纵向分区，统一管理外观、设备刷新、系统健康、更新和本地数据。
- 窄窗口下设备栏自动移动到内容区上方。
- 最大化和宽屏窗口下，概览、屏幕、文件及应用工作区自动切换为双列，并将内容宽度限制在 1400 px 以内；中等窗口恢复单列。

## 验证

- Release x64 自包含构建通过，0 个警告、0 个错误。
- 211 项单元测试全部通过。
- 本地启动烟测通过，应用进程正常保持运行，未生成崩溃日志。
- 发行脚本检查通过 23 项。
- Android 12 真机完成设备详情、Shell、应用读取、截图、Logcat、中文复杂路径文件与目录往返，以及四种镜像预设和 MP4/MKV 录制验证。
- 在 100% DPI 下完成 1920×1048 最大化、1280×800 和 600×650 三档桌面布局实测，工作区无横向裁切或偏移。

125%、150% 等非 100% DPI 缩放仍需在对应显示设备上补充最终验收。
