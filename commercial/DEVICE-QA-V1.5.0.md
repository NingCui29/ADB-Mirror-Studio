## 真机界面发现并修复的问题

1. TCP/IP 设备的标题和确认对话框重复显示序列号。修正目标标签组合规则。
2. 镜像运行时“开始镜像”和“停止镜像”同时可点击。改为按选中设备的会话状态互斥。
3. 只有一个镜像会话时仍允许网格、横向、纵向排列。改为至少两个会话才启用。
4. 未选择 APK、应用或设备时，安装、启动、强制停止、卸载和设备操作仍可点击。补充操作前置状态绑定。
5. 设备列表向 UI Automation 暴露 ViewModel 类型名。改为暴露设备显示名。
6. 顶级任务和设置入口隐藏在最小导航菜单中。改为紧凑图标导航，入口始终可见。
7. 600 px 窄窗口没有触发设备栏重排，标题和内容被压缩裁切。将响应式状态提升到页面根布局，并修正列宽切换。
8. 紧凑布局只够显示一个设备且滚动提示不明显。设备区域高度调整为 250 px，可直接显示两台常见测试设备。
9. 镜像预设选择框随内容收缩，当前值不易辨认。固定为 240 px 宽度。
10. 成功状态长期占用底部提示条且无法关闭。允许手动关闭，并在下一条状态出现时重新打开。
11. 最大化后设备工作区仍限制在 920 px，且页签内容偏向右侧形成大面积无效留白。增加 1500 px 宽屏断点、双列卡片布局和基于页签实际宽度的 1400 px 内容上限。

- 选中 TCP/IP 设备后，页头只显示一次 `mt 10.67.116.12:5555`。
- 未选择设备时设备相关操作禁用；选中设备后按能力恢复。

- 600×650 窗口下设备栏移动到内容上方，内容恢复完整宽度。
- 1920×1048 最大化窗口下四个操作页使用双列；终端区完整拉伸并居中；1280×800 自动恢复单列。
- Release 编译 0 警告、0 错误；211 项测试全部通过；发行脚本 23 项检查通过。

## 尚未覆盖

- APK 安装和卸载没有在生产设备上执行，避免改变设备应用状态。
- 重启、断开连接和启用 TCP/IP 没有执行，避免中断正在使用的远程设备。
- Windows 安装器未做本轮覆盖安装与卸载验收；安装器仍未进行 Authenticode 签名。

## 剩余已知问题

- Windows App SDK 的单实例注册受应用身份边界影响，已安装版本与便携版本仍可能同时运行；两者会共享 `%LOCALAPPDATA%\AdbMirrorStudio\settings.json`，并发修改设置时存在相互覆盖风险。当前应避免同时运行两种分发版本，后续版本需要增加跨分发形态的进程互斥。
