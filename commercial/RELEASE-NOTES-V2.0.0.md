# ADB Mirror Studio V2.0.0

预发布日期：2026-11-03。界面版本：`V2.0.0-2026.11.03`。

## 主要变化

- 重做工作区导航与主题：目标设备、屏幕镜像、文件管理、应用管理、终端，以及任务中心和设置；响应式布局与浅色/深色外观。
- 合并镜像开始/停止操作，补充设备连接引导、性能指标进度展示与成功提示自动收起。
- 设备 Shell 输入校验与 Windows findstr 误用提示。
- 离线和未授权设备不再启用在线操作按钮。
- 设置及连接历史保存失败保留错误提示；取消文件选择保留原上传队列。
- 卸载成功立即移除对应应用；刷新列表失败明确提示，迟到结果不覆盖新设备状态。
- 发布日期固定显示，数字版本与自动更新协议保持兼容。

## 升级与回退

退出旧版本后运行安装器覆盖升级；便携版请解压到新目录。沿用现有本机设置，无需手动迁移。回退时退出 V2.0.0，从 V1.9.0 Release 重新安装或解压运行；如需精确恢复设置，请在升级前自行备份本机数据目录。

## 验证与已知限制

Release 单元测试 323 项通过；Windows x64 自包含发布构建通过；27 项发行脚本检查及隐私审计通过。实际程序集版本读取确认日期展示与更新版本分离。详细范围见 [发布验收](https://github.com/NingCui29/ADB-Mirror-Studio/blob/master/commercial/DEVICE-QA-V2.0.0.md)。

本版标记为预发布，不替代最新稳定版的自动更新入口。本轮未完成实际桌面 UI、Android 真机端到端及安装/升级/卸载验收，不能用自动化测试替代这些结果。安装程序尚未配置 Authenticode 签名。
